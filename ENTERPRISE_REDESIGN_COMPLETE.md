## Quick Reference

### Using Premium Utilities

```tsx
// Glass morphism
<div className="glass">...</div>

// Premium shadow
<div className="shadow-premium">...</div>

// Glow effect
<div className="shadow-glow-blue">...</div>

// Gradient text
<span className="gradient-text">...</span>

// Hover lift
<div className="card-hover">...</div>

// Fade in animation
<div className="animate-fade-in">...</div>

// Staggered animations
<div className="animate-fade-in-up animation-delay-100">...</div>
```

### Button Examples

```tsx
// Premium primary button
<Button size="lg" variant="primary">
  Click Me
</Button>

// With icon
<Button icon={<Icon />} iconPosition="left">
  Save Changes
</Button>

// Loading state
<Button loading={true}>Processing...</Button>
```
